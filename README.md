# D2Helper

Бесплатный сайт‑помощник для Dota 2: сильные герои патча, разбор твоих матчей, тренировка драфта, мини‑игры и поиск пати.

## Как пользоваться

Большинство разделов открыты всем. Войди через Steam (кнопка «Войти через Steam» в шапке), чтобы сохранять рекорды, анкету и разборы. Пароль от Steam сайту не нужен: вход идёт на странице Steam, а мы получаем только твой ник и аватар.

Внизу экрана — навигация по разделам: **Главная, Играть, Тренер, Разборы, Инструменты, Профиль**.

### Главная
Сильные герои текущего патча по пяти позициям (листай стрелками) и свежие новости Dota 2. Новости про патч открываются с понятным списком изменений на русском; комментировать их могут вошедшие.

### Тренер — статистика твоих матчей
1. Открой «Тренер». После входа через Steam сайт сам найдёт твой профиль. Без входа вставь ссылку на профиль (Steam, OpenDota, STRATZ, Dotabuff), SteamID64 или ID из Dota 2 — можно смотреть и чужие профили.
2. Увидишь ранг, винрейт за последние 20 игр и список матчей с фильтром «Победы / Поражения». Нажми на матч, чтобы открыть его подробности.
3. Кнопка «Сводка» показывает винрейт за полгода и героев «в форме».

**Если пишет, что история закрыта:** в Dota 2 открой *Настройки → Общение* и включи **«Общедоступная история матчей»**. Сыграй хотя бы один матч, затем нажми «Проверить снова»; если не помогло — подожди 15–30 минут, данные появляются с задержкой.

### Разборы — AI‑разбор матча
Бесплатный разбор матча по реплею: оценка игры, ошибки на линии, ключевые эпизоды с таймингами и «как было бы лучше», карта смертей в драках.

1. Открой вкладку «Разборы» → «Разобрать матч» (нужен вход через Steam).
2. Выбери матч из своей истории и запусти разбор. Подойдут матчи не старше **двух недель**.
3. Подожди. Если реплей ещё не обработан, сайт попросит об этом сервис OpenDota — это может занять **до 15 минут**. Страницу можно закрыть: статус появится в списке разборов.
4. Открой готовый разбор из списка.

**Лимит:** 3 разбора в день (сколько осталось — видно на странице запуска). Если разбор не получился, лимит не тратится, и матч можно заказать заново. Если сервис перегружен, попробуй позже.

**«Что тренировать»** — вторая вкладка в «Разборах». Здесь собраны над чем стоит поработать (по последним трём разборам) и чек‑лист «План на следующие игры». Отмечай выполненное галочками — отметки хранятся в твоём браузере.

Не уверен, нужно ли тебе это? Посмотри «Пример разбора» — он доступен без входа.

### Инструменты
- **Драфтер → «Анализ»:** во время игры нажимай на слоты и добавляй героев Света и Тьмы, баны — справа увидишь оценку каждой команды, сильнейшую пару, лучший и худший матчап и подсказку, кого взять на свободную позицию. Ссылкой на драфт можно поделиться.
- **Драфтер → «Тренировка»:** сайт показывает пятёрку врагов, ты собираешь свою команду и жмёшь «Оценить драфт» — получаешь счёт 0–100 с разбором. Нужен вход. Иконка кубка — топ драфтеров месяца (считаются 5 лучших результатов), часы — история твоих тренировок.
- **Герои:** поиск и сетка героев, фильтры по атрибуту и позиции, «Сильные сейчас». На странице героя — на каких позициях играется, против кого силён и слаб, лучшие союзники, популярные предметы и кнопка «Взять в драфтер».

### Играть
- **Больше / Меньше** — угадай, у какого героя показатель выше (популярность, убийства или смерти). Рекорды сохраняются в профиле.
- **Квизы:** «Какая твоя позиция?» (5 вопросов) и «Подбор героя» под твою позицию и стиль.
- **Поиск пати** (нужен вход): создай анкету в профиле — ранг, позиции, режимы, любимые герои, Discord/Telegram — и ищи напарников или команду по фильтрам. Анкету можно «поднять» раз в сутки, скрыть или удалить. На неподходящую анкету можно пожаловаться через меню «⋯».

### Профиль
Твои аккаунты, анкета для пати, рекорды в играх, результаты квизов и место в топе драфтеров. Здесь же выход из аккаунта.

### Частые вопросы
- **Матчей нет или они старые.** Нажми «Обновить матчи» в «Тренере». Данные берутся из OpenDota и могут обновляться с задержкой.
- **Разбор недоступен.** Администратор сайта ещё не подключил языковую модель — пока можно смотреть пример.
- **Профиль по короткой ссылке `steamcommunity.com/id/…` не находится.** Вставь SteamID64, ID из Dota 2 или ссылку вида `…/profiles/…`.
- **Хочу оставить отзыв или сообщить об ошибке.** На главной есть ссылка на форму обратной связи.

# Для разработчиков

ТЗ и принятые решения — в [SPEC.md](SPEC.md). Проект готов; дальше — исправление багов и доработка деталей.

- **Бэкенд:** Go, chi, pgx, goose, slog — `backend/`
- **Фронтенд:** React 18, TypeScript, Vite, React Router 7, TanStack Query, Zustand, Tailwind CSS 4 — `frontend/`
- **База:** PostgreSQL 16

### Настройка

```bash
cp .env.example .env   # и заполнить ключи
```

Описание всех переменных — в [.env.example](.env.example). Что нужно по минимуму:

| Переменная | Зачем | Без неё |
|---|---|---|
| `SESSION_SECRET` | подпись входа и сессий | не стартует |
| `STEAM_API_KEY` | ники и аватары при входе, поиск профиля по `steamcommunity.com/id/…` | вход работает через OpenDota, ссылки с коротким именем — нет |
| `STRATZ_TOKEN` | мета по реальным позициям, «Убийства/Смерти» в «Больше/Меньше», матчапы драфтера | мета по общему винрейту, доступна только «Популярность» |
| `OPENDOTA_API_KEY` | выше лимит запросов | работает с низким лимитом |
| `LLM_API_KEY` | «Глубокий разбор» (бесплатный ключ OpenRouter, см. ниже) | разбор недоступен, страницы показывают пример |

Токен STRATZ выдаётся на stratz.com/api: нужен один привязанный Steam‑аккаунт и ≥100 открытых матчей. `PUBLIC_URL` в разработке можно оставить пустым — адрес сайта определится по запросу.

### Глубокий разбор матчей (AI)

Разбор бесплатный: на сайте нет оплаты, есть дневной лимит на пользователя (`ANALYSES_PER_DAY`, по умолчанию 3; неудавшиеся разборы его не тратят). Модель — любая OpenAI‑совместимая, выбирается тремя переменными в `.env`:

**Вариант 1 — OpenRouter, бесплатные модели (по умолчанию).** Заведи ключ на <https://openrouter.ai/keys> и впиши его:

```
LLM_API_KEY=sk-or-...
```

`LLM_BASE_URL` и `LLM_MODEL` уже подходят (`openrouter/free` сам выбирает свободную бесплатную модель, дальше идут запасные). У бесплатных моделей есть дневные лимиты провайдера — если они кончились, разбор вернёт «AI‑сервис перегружен» и не спишет лимит.

**Вариант 2 — локальная модель в Ollama** (бесплатно и без интернета; нужна видеокарта или терпение). Установи [Ollama](https://ollama.com), скачай модель (`ollama pull qwen2.5:7b`) и впиши:

```
LLM_BASE_URL=http://host.docker.internal:11434/v1
LLM_MODEL=qwen2.5:7b
```

Ключ в этом случае не нужен. Остальные OpenAI‑совместимые сервисы (Groq, Gemini, LM Studio) подключаются так же. После правки `.env` перезапусти бэкенд: `docker compose up -d backend`.

Разбор заказывается и смотрится во вкладке «Разборы»: там все твои разборы и отдельный экран «Что тренировать» (план и слабые места из последних разборов). Он строится по реплею матча из истории профиля: если OpenDota ещё не разобрала реплей, сайт попросит её об этом и подождёт до 15 минут. Матчи старше двух недель разобрать нельзя.

### Запуск через Docker

```bash
docker compose up --build
```

Сайт — <http://localhost:8000> (порт меняется через `FRONTEND_PORT`). Миграции применяются при старте бэкенда.

> Docker Desktop на Windows работает поверх WSL 2. Если он не стартует из‑за WSL — в PowerShell от администратора: `wsl --install --no-distribution`, затем перезагрузка.

### Разработка

Postgres и бэкенд в Docker, фронтенд на Vite:

```bash
docker compose up -d postgres backend
cd frontend && npm install && npm run dev   # http://localhost:5173, /api → localhost:8080
```

Без Docker: нужен Postgres (адрес в `DATABASE_URL`), затем `cd backend && go run ./cmd/server` и `npm run dev` во фронтенде. Витрина UI‑компонентов — <http://localhost:5173/dev/ui>.

### Проверки

```bash
cd backend  && go vet ./... && go test ./...        # + golangci-lint run, если установлен
cd frontend && npm run typecheck && npm run lint && npm run format:check && npm test && npm run build
```

```
backend/
  cmd/server/            HTTP‑сервер, сборка зависимостей, фоновые джобы
  internal/
    auth/                Steam OpenID, сессии, state
    clients/             opendota, stratz, steam, dota2 (datafeed патчей), telegram, httpx (лимиты, ретраи)
    coach/               «Тренер»: профиль, синк матчей, сводка, страница матча
    dota/                константы героев/патча, теги героев, ранги, SteamID, разбор ссылок профиля
    games/               «Больше/Меньше»: снапшот и рекорды
    quiz/                квизы: данные, подсчёт, подбор героев
    party/               анкеты и поиск пати: валидация, стоп‑лист, подъём, жалобы
    matchups/            матрица матчапов и синергий героев (STRATZ, фоллбэк OpenDota)
    drafter/             оценка драфта, тренировки, история и топ драфтеров за месяц
    heropage/            данные страницы героя: позиции, матчапы, союзники, предметы
    analysis/            глубокий разбор: признаки игры из реплея, проверка ответа модели, очередь и воркер (API: заказ, список, результат, лимит)
    llm/                 клиент OpenAI‑совместимых моделей (OpenRouter, Ollama…) с запасными моделями
    meta/                мета по позициям (STRATZ / OpenDota)
    news/ patchnotes/    новости Steam и патчноуты
    httpapi/             роутер, middleware, хендлеры по фичам
    store/               Postgres: пул, миграции, репозитории
  migrations/            SQL goose (встроены в бинарник)
  data/                  heroes_tags.json, quiz_*.json, positions.json, analysis_example.json
frontend/src/
  app/                   роутер, провайдеры, layout
  api/                   fetch‑клиент, типы, ключи запросов, endpoints/
  components/            ui/ (UI‑кит), dota/, coach/, analysis/, drafter/, quiz/, party/, news/, home/
  features/              хуки данных (useMe, useCoach, useGames, useContent…)
  lib/                   форматирование, позиции, ранги, логика игр и квизов
  i18n/ru.ts             все строки интерфейса
  pages/                 страницы по разделам (home, play, coach, reviews, tools, profile)
```
